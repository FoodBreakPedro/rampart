Rampart

How Rampart works

Rampart looks for security problems in your projects and keeps a score of how each one is doing. It checks in four ways, from free and quick to thorough.

The four kinds of check

Basic checks L1
Free scripts, about a minute. They search every saved version of the code for leaked keys and passwords, look for outside libraries with known security holes, and grade the security settings of each live web address.
Change review L2
AI agents read what a branch changed and look for mistakes. Uses tokens, usually few, since it reads only the changes.
Deep review L3
AI agents read the whole code, one group of files at a time. Uses the most tokens and takes a while.
Server check INFRA
Read-only commands on your own server (Docker, Supabase, n8n, WordPress) compared with a list of safe settings. The commands change nothing.

How a problem gets counted

In a change review, deep review or server check, AI reviewers suggest possible problems. Separate AI checkers then try to prove each one wrong. Only the ones a majority of checkers confirm become problems on this page. Basic checks come from tools, so their hits count as scanner hits until someone confirms them.

How the score works

Each project scores out of 100. Up to 40 points come from running each kind of check often enough. The other 60 start full, and each open problem takes some away: more for serious ones, less for scanner hits than for confirmed ones. Tips cost nothing. Grades: A from 90, B from 75, C from 60, D from 40, F below 40.

Words on this page

Part
A piece of a project that Rampart checks on its own, such as an app's code or the server behind it.
Up to date, overdue, out of date
Each kind of check should run every so many days. Run within that time it earns all its points; within twice that time, half; after that, none.
How bad: urgent, serious, moderate, minor
How much harm a problem could do if someone used it.
Confirmed, scanner hit, tip
Confirmed: AI checkers agreed it is real. Scanner hit: a tool flagged it and nobody has confirmed it yet. Tip: extra protection that is worth adding but costs no points.

More words

Your decision
For each problem you can say it is fixed, not a real problem, or accepted as is. The last two need a reason and stop it costing points.
Runner
A Claude Code session on your computer running /rampart watch. It picks up the checks you start from this page.
Check lists
The lists Rampart works from: the kinds of mistake to look for in each kind of part, and the read-only server commands to run. They come with Rampart.
Code groups
A deep review packs the code into groups of files. An AI reviewer reads each group and looks for several kinds of mistake from its check list at once.
