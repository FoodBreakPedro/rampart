## How to resume on another machine

1. Clone and check the branches out as worktrees (the SDD process assumes one worktree per plan):
   ```bash
   git clone git@github.com:FoodBreakPedro/rampart.git && cd rampart
   git worktree add .worktrees/hunt-engine feat/hunt-engine
   git worktree add .worktrees/live-dashboard feat/live-dashboard
   npm test && npm run validate
   ```
2. For each plan, start a Claude Code session on **Opus** in the worktree and give it this brief: "Resume `docs/superpowers/plans/<plan>.md` with `superpowers:subagent-driven-development`. The ledger is `docs/superpowers/handoff/<plan>-ledger.md`: copy it to `.superpowers/sdd/<plan-file-stem>/progress.md` (run the skill's `sdd-workspace` script to get the exact path) so the skill resumes at the first task without a `complete` line. The last WIP commit on this branch holds the implementer's in-progress fix edits; start that task's fix round by dispatching a fresh implementer with the brief, the report file (lost; rebuild from the ledger) and the open findings listed in the ledger. Sonnet implements mechanical tasks, Opus the packs/agents/page/recipes. Finish with a draft PR to `main`."
3. The `claude` CLI must be signed in (`claude auth status`) for the fresh-session acceptance steps (`claude --plugin-dir . -p …`).
4. Install for daily use: `/plugin marketplace add FoodBreakPedro/rampart`, then `/plugin install rampart@rampart`. Or `claude --plugin-dir <checkout>`.
