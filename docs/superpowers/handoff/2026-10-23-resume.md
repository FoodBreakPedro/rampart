## How to work on it

- Plans run with `superpowers:subagent-driven-development` on Opus: one worktree per plan, the plan's ledger copied into the skill's SDD workspace (its `sdd-workspace` script gives the path) so it resumes at the first task without a `complete` line. Sonnet implements mechanical tasks, Opus the packs, agents, page and recipes. Each plan ends with a draft PR to `main`.
- The `claude` CLI must be signed in (`claude auth status`) for the headless acceptance steps (`claude --plugin-dir . -p …`).
- Install for daily use: `/plugin marketplace add FoodBreakPedro/rampart`, then `/plugin install rampart@rampart`. Or `claude --plugin-dir <checkout>`.
