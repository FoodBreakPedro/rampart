# Rampart

Rampart is a Claude Code plugin for layered security and vulnerability reviews across all your systems. It inventories what you run, then audits it in layers (L1, L2, L3, and infrastructure), has each finding independently verified, keeps a per-user record of results and dispositions, and shows a scored dashboard.

Status: pre-release
